<p>Mau bikin plugin tapi bingung bikin Options page?<br/>
Pake Easy Options aja, sekarang udah update ke versi 1.6 loh.</p>

<p>Features:</p>

<p>*  Easy to use<br/>
*  Unlimited options page<br/>
*  Support tabbed options page<br/>
*  Custom icon<br/>
*  Various field types: checkbox, checkboxgroup, text, textarea, dropdown_pages, image.<br/>
*  Flexible menu location. Where you want to place the menu for options page is your choice.<br/>
*  Each option group is saved in one row of wp_options table, no wasting your database.</p>

<p>v1.6 Changelog:</p>

<p>*  Change apply_filters to do_action hook before and after form<br/>
*  Add actions to $defaults property, so that it will be easier to specify where actions should be fired. (eg, on current plugin page only)<br/>
*  Add field type image (using builtin plupload upload method)<br/>
*  Prevent menu_position conflicts with another plugin<br/>
*  Now you can use multiple field name, eg photo[], this will return array on output.</p>

<p>Question and feedback always welcome.</p>
