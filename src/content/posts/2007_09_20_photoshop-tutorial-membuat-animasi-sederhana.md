Tutorial Membuat Animasi Sederhana (Photoshop - ImageReady)

![tut-avatar-result](/images/uploads/1788712470453_tut-avatar-result.gif)

Selain untuk pengolahan foto (photo editing) dan mendesain web (web design), program Adobe Photoshop juga bisa digunakan untuk membuat animasi sederhana dalam format gif.

Kenapa sederhana? Yah, karena memang tidak bisa untuk membuat animasi sekompleks animasi Flash atau program animasi lainnya. 

Animasi yang dihasilkan dari photoshop disimpan dalam file berformat .gif (graphic interchange format).

Berikut langkah-langkahnya:

<b>1. </b>Buka program <span style="color: red;">Adobe Photoshop,</span> klik File New, Width=80 pixel Height=80 pixel



![tut-avatar-01](/images/uploads/1788712160104_tut-avatar-01.gif)



Biarkan isian yang lain seperti adanya, klik <span style="color: blue;">OK </span>atau tekan <span style="color: blue;">Enter</span>

<b>2.</b> Buatlah sebuah layer baru dengan menekan tombol <span style="color: blue;">Ctrl + Shift + N</span>, atau kalau mau capek gunakan menu <span style="color: blue;">Layer --&gt; New --&gt; Layer</span>

<b>3. </b>Tekan huruf <span style="color: blue;">U</span> untuk menuju tool Shape Tool, tekan tombol kombinasi Shift + U dan pilih <span style="color: red;">Custom Shape Tool</span>



![tut-avatar-02](/images/uploads/1788712187840_tut-avatar-02.gif)



<b>4. </b>Klik kanan pada bidang gambar anda, akan ada tampilan kumpulan shape tool siap pakai, pilih yang berbentuk bunga salju. Jika tidak ada klik tombol panah yang ada di sebelah kanan atas kotak tersebut.



![tut-avatar-03](/images/uploads/1788712208998_tut-avatar-03.gif)



Jika ada kotak dialog konfirmasi, pilih <span style="color: blue;">Append</span>

<b>5. </b>Pada gambar-gambar yang muncul, pilih <span style="color: red;">snowflake1</span>. Tariklah cursor anda dari sudut atas kanan ke sudut atas bawah untuk membuat shape. Tekan tombol <span style="color: blue;">Shift </span>supaya dimensinya proporsional. Sehingga gambarnya menjadi seperti di bawah ini:



![tut-avatar-04](/images/uploads/1788712226654_tut-avatar-04.gif)



<b>6. </b>Tekan <span style="color: blue;">Ctrl + J</span> tiga kali, untuk membuat duplikasi layer, atau klik kanan layer pada pallete layer, klik <span style="color: blue;">duplicate layer.</span> Sehingga pallete layer menjadi seperti ini :



![tut-avatar-05](/images/uploads/1788712240634_tut-avatar-05.png)



<b>7.</b> Klik menu <span style="color: blue;">Window --&gt; Style</span> untuk menampilkan pallete style, klik pada&nbsp; panah di pallete style dan pilih <span style="color: red;">Web Style</span>, pilih pilih Append pada kotak dialog yang muncul.



![tut-avatar-06](/images/uploads/1788712267386_tut-avatar-06.gif)



Kemudian pallete style akan menjadi seperti ini:



![tut-avatar-07](/images/uploads/1788712278592_tut-avatar-07.png)



Pastikan ada style red paper clip, yellow paper clip, green paper clip, dan blue paper clip.

<b>8. </b>Terapkan style tersebut pada masing-masing layer, layer1 style red paper clip, layer 1 copy style yelow, layer1 copy 1 style green, layer1 copy 2 style blue.

Caranya klik layer pada pallete layer, kemudian klik pada style yang diinginkan.

Masing-masing style ini mempunyai shadow dan ini sebaiknya dihilangkan, untuk melakukannya klik pada layer 1, kemudian klik tombol <span style="color: red;">Add a layer style </span>yang ada di bawah pallete layer, hilangkan centang pada <span style="color: red;">Drop Shadow</span> dengan mengekliknya. Lakukan ini pada layer-layer yang lainnya.



![tut-avatar-08](/images/uploads/1788712297531_tut-avatar-08.png)



<b>9. </b>Selanjutnya lakukan transformasi gambar, putar layer1 copy ke arah jarum jam sebesar 30 derajat, caranya klik layer1 copy pada pallete layer, tekan tombol <span style="color: red;">Ctrl + T</span> dan arahkan mouse ke sudut-sudut yang dikelilingi kotak-kotak kecil dan putarlah ke arah kanan. Kemudian tekan Enter



![tut-avatar-09](/images/uploads/1788712309130_tut-avatar-09.png)



Lakukan hal yang sama pada layer1 copy 3, yaitu memutarnya ke kanan 30 derajat.

<b>10. </b>Tahap pembuatan layer sudah selesai, dan sekarang tinggal menganimasikannya di Image Ready. Tapi upps, untuk membuat animasi avatar anda menjadi transparan, anda harus menghapus layer background. Untuk melakukannya, klik pada layer background kemudian klik pada gambar tong sampah di bawah pallet layer, atau klik kanan layer background, klik <span style="color: red;">delete layer</span>.



![tut-avatar-10](/images/uploads/1788712346625_tut-avatar-10.png)



<b>11. </b>Sekarang menuju program <span style="color: red;">Image Ready</span>, tekan tombol <span style="color: blue;">Ctrl + Shift + M </span>untuk membukanya.

Pastikan pallete Animation ditampilkan, jika tidak klik menu Window, pilih Animation untuk menampilkannya.



![tut-avatar-11-1](/images/uploads/1788712368975_tut-avatar-11-1.png)



<b>12. </b>Klik pada panah kecil di sebelah kanan atas pallete Animation, dan pilih Make Frames From Layers



![tut-avatar-12](/images/uploads/1788712416019_tut-avatar-12.png)



<b>13. </b>Preview animasi yang baru anda buat denga menekan tombol play, gunakan frame delay untuk menetukan durasi antar frame dalam satuan detik. Supaya animasi kelihatan cepat, biarkan saja bernilai 0 seconds.



![tut-avatar-13](/images/uploads/1788712436685_tut-avatar-13.png)



<b>14. </b>Animasi sudah siap, saatnya menyimpan. Tapi sebelum disimpan sebaiknya anda melakukan optimasi dulu, supaya file hasilnya nanti tidak terlalu besar kilobytenya. 

Untuk melakukannya, klik <span style="color: red;">tab 4-Up</span> pada jendela preview dan kemudian pilih/klik pada gambar preview yang kilobytenya paling kecil.



![tut-avatar-14](/images/uploads/1788712458880_tut-avatar-14.png)



Setelah simpan dengan perintah <span style="color: red;">File, Save Optimized As </span>atau tekan tombol <span style="color: blue;">Ctrl+Shift+Alt+S</span>, beri nama sesuai dengan keinginan anda.
