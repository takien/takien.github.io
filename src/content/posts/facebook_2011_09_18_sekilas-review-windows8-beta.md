<p>Sekilas review windows8 beta</p>

<p>( + )</p>

<p>+ instalasi relative cepat (seperti halnya win7)</p>

<p>+ boot up cepat.</p>

<p>+ pake home screen keren</p>

<p>+ pindah apps dengan cara slide (tekan mouse di kiri layar, kemudian drag ke tengah, di slide dari sebelah kanan gk bisa)</p>

<p>+ untuk kembali ke home screen, tekan Window key di keybord.</p>

<p>+ desktop style lama masih ada (gk beda dgn win7)</p>

<p>+ program2 bawaan win8 (support full screen tanpa taskbar/titlebar, keren ajib, jadi pingin pake monitor touch screen), sepertinya nantinya program2 akan support fitur ini.</p>

<p>+ support multiple boot (ane pake 3 os XP,7,8)</p>

<p>+ most of program yang run di 7, run di 8</p>

<p>+ performance bagus</p>

<p>( - )</p>

<p>- tidak bisa diinstal di virtual box (pada bbrp machine, termasuk di pc ane)</p>

<p>- IE always sucks as expected: keyboard hang, loading lambat. (penyakit keturunan + penyakit baru)</p>

<p>- Tampilan tidak bisa full screen di monitor ane (menyisakan 2 cm black area di sekeliling layar, gk tau setelannya dimana). Driver VGA & monitor udah diinstal tapi kyknya gk masup.</p>

<p>- Restart lamaaaaaaaaaa (mungkin krn baru 1x restart, tapi gk tau nantinya)</p>

<p>- button shutdown/restart gk ada, baik di start menu, home, maupun sudut kanan. (pae ctrl+alt+del, baru muncul)</p>

<p>- delete file di windows explorer tidak ada dialog confirmasi, langsung masup ke tong sampah.</p>

<p>missing features:</p>

<p>. cara close program yg full screen gimana?, masa harus pake crtl+alt+del :D</p>

<p>. seharusnya di atas layar bisa didrag untuk melihat menu/notifikasi kyk android.</p>

<p>bugs:</p>

<p>. ane set high contrast ON, ketika udah di OFF kan, beberapa area masih black :D</p>
