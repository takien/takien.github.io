<p>Dokumentasi pengerjaan antarmuka (UI) halaman administrasi kustom untuk WordPress di <code>http://localhost/administrasi</code> yang pernah saya bagikan ke grup Facebook <strong>W3 kaskus</strong> (komunitas Webmaster &amp; Web Developer Kaskus) pada akhir Januari 2011.</p>

<p>
  <img src="/images/2011/01/wordpress-custom-admin-page.jpg" alt="Wordpress custom admin page, by me" title="Wordpress custom admin page" class="rounded-lg my-6 max-w-full h-auto shadow-md" loading="lazy" />
</p>

<p>Pada eksperimen ini, halaman administrasi dibuat mandiri tanpa menggunakan panel bawaan <code>wp-admin</code> standar. Panel ini dirancang lebih ringkas dan ramah pengguna dengan menu tabulasi:</p>

<ul>
  <li><strong>Artikel</strong>: Memuat sub-menu <em>Artikel Terbit</em>, <em>Artikel Tersimpan</em>, dan <em>Artikel Terhapus</em> lengkap dengan tombol <em>Tulis Artikel</em> dan penomoran halaman (paging).</li>
  <li><strong>Gallery</strong>: Pengelolaan media gambar.</li>
  <li><strong>Video</strong>: Manajemen konten berbasis video.</li>
  <li><strong>Halaman</strong>: Pengelolaan halaman statis.</li>
</ul>
