<p>Tahun 2004 mulai mengenal PHP dari sebuah buku terbitan elexmedia, saya rasa itu sangat rumit waktu itu, karena ada error yang tidak saya mengerti padahal saya sudah mengikuti panduan dari buku secara detail. Itu membuat saya putus asa, selama 2-3 tahun saya tinggalin, karena saya anggap itu terlalu sulit buat saya. saya cuma berharap suatu saat akan bisa memahami nya, tanpa melakukan apapun.</p>

<p>Hingga sekitar tahun 2007 saya mulai mempelajarinya kembali, ketika waktu itu kenal dengan CMS WordPress, phpBB dll. Kenal WordPress adalah sesuatu banget, karena amazingly saya yang tidak paham PHP bisa memulai membuat website berbasiskan PHP. Dari situ mulai timbul minat lagi untuk mempelajari PHP lebih mendalam.</p>

<p>Dengan adanya komunitas W3 kaskus saya banyak belajar dari situ, berdiskusi dan bertanya kepada teman-teman, terutama agan Ian Hehe Lubis dan Alm Pungky Hehe Putera</p>

<p>Saya sangat aktif di sub-forum W3 di kaskus, karena banyaknya antusias teman-teman yang juga sama-sama belajar.</p>

<p>Dengan pengetahuan yang sangat terbatas saya nekat melamar kerja di tahun 2009 di sebuah perusahaan untuk mengelola website nya.</p>

<p>Dari situ berbagai pengetahuan baru saya dapatkan, tidak lupa saya masih menggunakan w3 kaskus untuk berdiskusi ketika ada masalah dalam hal pengembangan website.</p>

<p>Tidak menyangka semakin ke sini saya semakin menyukai bidang racik-racik website ini sampai sekarang hingga menjadi matapencaharian utama saya.</p>

<p>Perjalanan mempelajari dan menggunakan PHP dalam menunjang pekerjaan saya begitu indahnya hingga suatu saat sekelompok anak-anak alay membuat istilah PHP itu adalah singkatan dari Pemberi Harapan Palsu. Aduh.</p>
