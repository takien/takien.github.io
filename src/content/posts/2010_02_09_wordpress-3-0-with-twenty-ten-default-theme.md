<p>I just download and install alpha version of WordPress Version 3.0. At a glance, there are no major changes that I can see. After installation process that run as simple as usual, I walk through menus in the Dashboard and found a new sub-menu named &#8220;Network&#8221; under the Tools menu. As I have heard before that in version 3.0 WordPress would be integrated with WordPress MU with <a href="https://web.archive.org/web/20160217012000/http://dougal.gunters.org/blog/2010/01/25/wordpress-3-0-multisite-terminology">Multi-Site</a> feature. It’s mean that you can multiply your site easily without Installing WordPress MU.</p>
<p>Navigate other menus, there is nothing striking until my mouse clicked on the &#8220;Appearance&#8221;. There seems to be a new stuff. The new default theme entitled &#8220;<em>Twenty Ten 0.7<strong> </strong>by the WordPress team</em>&#8220;, cool.  There’s a new atmosphere in my WordPress instead of seeing Kubrick theme for several years.</p>
<p>My curiosity led to Theme Editor that may also have some changes there. A little difference with previous version in the lists of the theme file name. The file title and file name are separated into two lines. Look quite neater.</p>
<p>At the bottom of file lists, there is a new stylesheet file named &#8220;<em>editor-style.css</em>&#8220;. I hope my guess’ right, it is the css style file to be used in editor page when I write or edit a post. I think it will be useful for those who create a new post from the dashboard, but not for me who prefer to write using Windows Live Writer.</p>
<p>That’s my story when testing WordPress 3.0 alpha &#8212; <em>development version (3.0-alpha)</em>&#8212; which may a lot of changes will be added  until the final version released.</p>
