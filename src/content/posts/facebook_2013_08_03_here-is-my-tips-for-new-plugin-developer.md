<p>Here is my tips for new plugin developer</p>

<p>Diminta bule tentang tips plugin developer buat pemula. Nggak terasa tertulis sebanyak ini. Padahal kalau ngeblog gk pernah ada ide :'(</p>

<p>Share disini aja lah :D</p>

<p>Here is my tips for new plugin developer:</p>

<p>1. Before everything</p>

<p>- Before you decide to make a plugin and publish it as opensource (to  WordPress org), it's recommeded that you make some research to know if  your plugin will be useful to others (and make sure there's no identical  plugin out there)</p>

<p>2. Make your plugin attractive</p>

<p>- Naming, name must be easy to  remember, representative, and simple. Avoid embed your name (or your  website,company etc) in your plugin name. Do not use trademark name.</p>

<p>- Cover image, plugin with cover image is more attractive to the user.  Prepare image named banner-772x250.png, place it on /assets directory   (/assets directory is in the same level with /trunk directory)</p>

<p>- Screenshots, don't forget to include screenshots in your plugin  (place it under /assets directory, named screenshot-1.png and so on),  give description for each screenshot.</p>

<p>3. Give support and accept feedback</p>

<p>- Always check for your plugin support forum on WordPress org. Answer the questions from the user.</p>

<p>- Some users usually post some feedbacks/critics to your plugin. Do not be offended if they give negative feedback. Note each feedback for your future plugin development (update).</p>

<p>4. Keep update</p>

<p>- What to update? the first thing you must  update is users request. As in point #2 above, you should note all  feedback and make it as new feature/fix in the next update.</p>

<p>5. Assets</p>

<p>- You do not need to create all assets your own, such as CSS, JS, Icon,  Image etc. There're many resource over the Internet. Make sure they're  licnesed under GPL, Creative Common or opensource.</p>

<p>- If you're unsure, ask the creator if their stuff can be used in your plugin.</p>

<p>- Give credit to the author, if you use those assets don't forget to give feedback link to the original author.</p>

<p>6. Coding</p>

<p>- Use WordPress coding standard to code your plugin</p>

<p>- Give comment to your code. It will help you in the next development and others.</p>

<p>- Avoid use WordPress or PHP deprecated functions.</p>

<p>- Pay attention with security issues.</p>

<p>- Do not encode your code, otherwise it will be rejected by WordPress plugin reviewer.</p>

<p>- Make sure you test your plugin in some WordPress instalation (current  version and previous version), also test on live site (not only on  localhost), if possible also test on diffrent server environment (eg.  Linux and Windows)</p>

<p>7. Don't</p>

<p>- Do not force users to donate you. I saw some plugin  author placed BIG DONATE BUTTON on plugin setting page and keep alert  us to donate. This is kind of annoying. They will donate if they want  to.</p>

<p>8. Promote your plugin</p>

<p>- Do not spam to promote your plugin</p>

<p>- Use social (Twitter, Facebook etc) to share your plugin</p>

<p>- Post a video tutorial about your plugin in Youtube will boost your plugin popularity</p>

<p>- Post your plugin in your blog/website</p>

<p>- Use your own plugin in your client project if needed (If you're web developer)</p>

<p>9. Use it</p>

<p>- You should also use your own plugin for your own wesite. Act as you  use other's plugin. By doing this you will know what your plugin advantages and disadvantages</p>
