<p>May be you see it everyday, a seamless-continuous  marquee in the Twitter homepage shows the current trending topic.  It&#8217;s damn good with fading background and short description in a tooltips.</p>
<p>If you like that marquee and want to put it in your website/blog,<span style="text-decoration: line-through;"> I have write such script using jQuery and CSS3</span> I just stolen a bunch of jQuery and CSS code from Twitter, clean it up and made to work standalone. 😀</p>
<p>All you need to do is edit the CSS (marquee width, background, text color etc) and image to fit to your need and drop it into your website or blog.</p>

<p>It&#8217;s nothing easier than to try it yourself and the following links will tell you everything.</p>
