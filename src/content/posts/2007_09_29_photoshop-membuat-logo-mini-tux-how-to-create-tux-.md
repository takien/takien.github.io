**2. Setelah terbuka lembaran baru otomatis jadi layer background... **


sekarang kita buat layer baru di atas layer background... caranya biasa lo Ctrl + Shift + N

<div class="text-center"><img src="/images/designkillers/tux/03-buat-layer-baru.gif"></div>
-

**3. Nah... perlu penjelasan sikit disini...nih **

Kita gak langsung buat logo tux nya yah... soalnya udah kucoba gitu malah ribet.. huehuehueeh...

Supaya lebih enakan nantinya, kita buat Style aja dulu... terutama style yang sering digunakan nantinya. Jadi sewaktu diperlukan, tinggal panggil aja dari style yang udah kita simpan.

Ada tiga style yang perlu kita buat disini... 
1. Style bias-putih (untuk memberi kesan pantulan cahaya), 
2. style gradasi-orange (memberi warna pada kaki dan paruh), 
3. dan style hitam.

Untuk style (layer style) dari menu <b>Layer --&gt; Layer Style --&gt; Blending Options...</b>

atau cara singkat, klik kanan layer1 pilih <b>Blending Options...</b>

<div class="text-center"><img src="/images/designkillers/tux/04-blending-option.gif"></div>

<b>3a. </b>Setelah terbuka dialog Layer Style dan sebelum di pilih style apapun...
Kita tentukan dulu <b>Fill Opacity </b>nya menjadi <b>0</b>, supaya style bias-putih ini nantinya transparan. 

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

Oke.. masih dalam jendela layer style, pilih <b>Gradient Overlay</b>, dan klik bar gradient di sebelah kanannya untuk mengeditnya.

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

Klik pada slider-slidernya, dan berikan nilai berikut

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

Akhiri dengan mengeklik OK,
dimana kita kembali ke jendela Layer Style.. (Jangan mengeklik OK disini yah.. <img src="/images/designkillers/ym/smiley.gif" alt="Smiley"> )
Karena kita mau menyimpan style yang barusan kita buat, makanya kita klik <b>New Style </b> yang ada di kanan atas (dibawha tombol OK)...

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

Maka akan muncul kotak dialog lagi, berikan namanya, <b>bias-putih</b>

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

Oke... selesai satu style... oops... tetep jangan tutup Layer Style dulu yah..

<b>3b. </b> Sekarang kita kembalikan setingan layer style ke awal (reset), caranya tekan tombol Alt, nah perhatikan tombol Cancel di bawah tombol OK, dia akan berubah menjadi tombol Reset sektika.. hehehhe.. klik lah....

<div class="text-center"><img src="/images/designkillers/tux/11-reset.gif"></div>
Langkah selanjutnya, hampir sama dengan style Bias-Putih tadi, bedananya disini kita tidak perlu merubah Fill Opacity menjadi 0 (ingat itu)... jadi kita langsung ke <b>Gradient Overlay</b>... kemudian klik bar gradient untuk mengeditnya.

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

Disini juga tidak perlu mengganti opacity, yang perlu diedit cuma warnanya doang...
1. Sebelah kiri berikan warna <b>Orange (FF6E02)</b>
2. Sebelah kanan berikan warna <b>Kuning (FFFF00)</b>

Sama seperti tadi juga, klik OK satu kali.. kemudian klik New Style, dan berikan nama style nya <b>gradasi-orange</b>.

<b>3c.</b> Style Hitam,&nbsp; masih seperti cara pertama dan kedua tadi, cuma bedanya ini warnanya hitam semua (000000).

Akhiri dengan menutup jendela Layer Style. (jangan menekan OK, tapi cancel aja. karena udah disimpan tadi style nya)

Setelah ditutup, akan ada style baru di pallete style (kalau belum muncul, munculkan melalui menu <b>Window --&gt; Styles</b>

<div class="text-center"><div class="text-center"><img src="/images/designkillers/tux/style-setelah-simpan.gif"></div></div>
Nah, nanti sewaktu-waktu style ini diperlukan, tinggal pilih layer yang mau diberi style, trus klik aja style tersebut...


**4. Masalah style udah siap, sekarang kita masuk ke pembahasan inti... bagaimana sebuah linkaran bisa disulap menjadi pinguin hehhehee...**

Untuk membuat lingkaran kita menggunakan shape elipse tool (U):

<div class="text-center"><img src="/images/designkillers/tux/12-elipse-tool.gif"></div>
-- Mulailah membuat gambar lingkaran di area kosong menggunakan elipse tool tadi... (Gambar A) dan beri <b>style hitam.</b>
-- Buat linkaran kedua dengan posisi agak kebawah. (Gambar B)
-- Lingkaran kedua tadi diberi style <b>bias-putih</b>, caranya pilih layernya, klik style nya... (Gambar C)

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

-- Buat lingkaran lagi mendekati batas atas lingkaran utama (Gambar D)
-- Lingkaran itu diberi style bias-putih (Gambar E)
-- Buat lagi lingkaran untuk mata sebelah kiri, (Gambar F) dan juga kanan (Gambar G),

perlu diperhatikan mata sebelah kiri lebih lonjong dan lebih besar, sementara yang kanan bulat dan kecil.

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

-- Sekarang buat Bola matanya, dua lingkaran bulat yang diberi style Hitam, (gambar J, langsung lompat ke J dari G wkkawkkakaw... sori tadi kelupaan urutan abjad..&nbsp; &nbsp;<img src="/images/designkillers/ym/grin.gif" alt="Grin">)
dan ditengahnya diberi linkaran lebih kecil lagi dengan style bias-putih (Gambar K)....

Jadi deh matanya yang belo.. <img src="/images/designkillers/ym/smiley.gif" alt="Smiley">

**5. Saatnya membuat paruh... hehhehe**

Paruhnya lagi-lagi dari lingkaran juga wkawkakkakakkaa.... tiada hari tanpa linkaran deh...

-- Oke.. langsung aja buat sebuah linkaran sepantasnya di bawah kedua mata si pinguin tadi.
beri style <b>gradasi-orange</b>. (Gambar L dan gambar M).

-- Selanjutnya gambar N (di zoom biar jelas wekekwkekwe)... diapain tuh hidungnya..
dimancungin lah, masa hidungnya bulet gitu kyk bagong.. wekwkkwwe... <img src="/images/designkillers/ym/grin.gif" alt="Grin">

Wah, kyknya perlu alat khusus neh.. iya emang.. lingkaran bisa di edit bentuknya pake <b>Direct Selection Tools </b> (Tekan huruf A)... pastikan cursornya berbentuk panah kecil berwarna putih, kalau cursornya berwarna hitam&nbsp; <b>bernama path selection tool </b>, berfungsi untuk menyeleksi dan memindahkan objek.&nbsp; Untuk switch antara direct selection tool sama path selection tool tekan Shift + A

<div class="text-center"><img src="/images/designkillers/tux/12a-path-select-tool.gif"></div>

Tariklah setiap node di setiap sisi lingkaran sedemikian rupa seperti di gambar N, Gambar O, Gambar P dan gambar Q. sehingga berbentuk menjadi paruh yang runcing.

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>

-- Waoww... dah jadi blom paruhnya... tenang sikit lagi kok....
tinggal kasih pantulan cahaya di paruhnya... caranya pilih layer, tekan Ctrl + J,
kemudian layer hasil duplikat di transform menjadi lebih kecil dari layer aslinya (Gambar R)

-- Setelah di transform menjadi lebih kecil, kemudian di beri Style <b>bias-putih</b> (Gambar S).

<div style="border:1px dashed red;text-align:center;padding:10px">IMAGE MISSING</div>


**6. Sekarang membuat tangan...**

cara kerjanya tidak jauh beda dengan pembuatan paruh tadi, yaitu sama-sama berasal dari linkaran, di ubah bentuknya menggunakan direct selection tools dan di beri pantulan cahaya... (Gambar T, Gambar U, Gambar V, Gambar W)
Buatlah tangan sebelah kiri / atau kanan dulu kemudian sebelahnya lagi tinggal duplikat.

Nah... setelah dikasi tangan-kiri dan kanan hasilnya seperti Gambar X
