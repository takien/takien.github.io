<p>Membuat Theme WP #1 - style.css</p>

<p>Dalam theme WP, salah satu file yang diperlukan adalah style.css</p>

<p>Selain untuk menempatkan CSS, file ini juga untuk menyimpan informasi theme tersebut, seperti nama theme, author dll.</p>

<p>Jika file style.css tidak ada, maka theme akan error.</p>

<p>Berikut contoh isi informasi dari style.css</p>

<p><code></p>

<p>/*</p>

<p>Theme Name: Twenty Ten Theme</p>

<p>URI: http:// wordpress. org/</p>

<p>Description: The 2010 default theme for WordPress.</p>

<p>Author: wordpressdotorg</p>

<p>Author URI: http://wordpress. org/</p>

<p>Version: 1.0</p>

<p>Tags: black, blue, white</p>

<p>License:</p>

<p>License URI:  General comments (optional). */</p>

<p></code></p>

<p>Dari contoh diatas, yang wajib adalah Theme Name, selain itu opsional.</p>

<p>Theme name harus unik.</p>
