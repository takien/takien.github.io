<p>ModalDengkul.js is a jQuery image lightbox inspired by Facebook. Unlike usual lightbox, ModalDengkul.js places title and description in the right side of the modal box.</p>
<p><strong>Screenshots:</strong></p>
<div id="attachment_1218" style="width: 624px" class="wp-caption aligncenter"><a href="https://web.archive.org/web/20160121163544/http://img.takien.com/2013/04/modaldengkul.js-ss-1024x626.jpg"><img src="/images/2013/04/modaldengkul.js-ss-1024x626.jpg" alt="ModalDengkul.js screenshot" title="" class="rounded-lg my-6 max-w-full h-auto shadow-md" loading="lazy" /></a><p class="wp-caption-text">ModalDengkul.js screenshot</p></div>
<p><strong>Some features:</strong></p>
<ul>
<li>Responsive</li>
<li>CSS3 animation</li>
<li>Lightweight</li>
<li>Keyboard navigation (next, close etc)</li>
</ul>
<p><strong>Tested browser:</strong></p>
<ul>
<li>Mozilla Firefox 20</li>
<li>Google Chrome 26.x</li>
<li>Android Browser</li>
</ul>
