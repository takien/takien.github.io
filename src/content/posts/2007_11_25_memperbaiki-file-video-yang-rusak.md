Mungkin anda pernah mengalami hal ini juga, file-file video yang tidak bisa diputar, tidak bisa di skip/dipercepat pake slider atau membuat player hang ketika diputar. Kenapa file video bisa rusak? Bisa disebabkan oleh proses transfer yang tidak sempurna, misalnya pengcopian dari CD, proses download yang korup karena koneksi terganggu, atau proses capture yang terganggu. Kalau sekedar tidak bisa dipercepat sih mungkin masih bisa ditoleransi, tapi kalau tidak bisa diputar? Wah, ini yang kadang menjengkelkan. &#8220;Downloadnya udah nunggu lama, eh malah korup!&#8221;. Begitulah kira-kira keluhannya. Apakah semua file video yang rusak bisa diperbaiki? Bisa iya bisa juga tidak, tergantung tingkat kerusakan dan tingkat keberuntungan anda juga. <span id="more-185"></span></p>
<p>Salah satu program yang bisa digunakan untuk mendeteksi file video yang rusak adalah <a title="Video Fixer Download" href="http://www.video-fixer.com/download.htm" target="_blank">Video Fixer</a>, dari namanya juga udah ketauan kalau makhluk itu bertugas memperbaiki video. Setelah di download dan diinstal program Video Fixer bisa diakses dari Start menu di komputer anda. Kalau program Video Fixernya ngambek dan tidak bisa dipakai lebih dari 10 hari sebaiknya disertakan juga program pendukungnya yang barangkali bermana <strong>Video Fixer Fixer</strong> 😀 </p>
<p>Oh iya kok lupa. Lalu bagaimana cara memperbaikinya? Pertama-tama tentu saja dibuka program Video Fixer nya, di bagian jendela program ada tombol Add File untuk menambahkan file yang akan di perbaiki. Sebaiknya lakukan Checking dengan mengeklik tombol <em>Check </em>untuk mengetahui apakah video bisa diperbaiki atau tidak. Jika statusnya <em>Can be fixed,</em> teruskan perjuangan anak muda dengan menekan tombol <em>Fix </em>untuk memerintahkan program supaya bekerja untuk kita. Dalam program ini juga ada fitur <em>auto backup</em>, dimana jika fitur ini diaktifkan maka file yang lama tidak akan terganggu dan file hasil fixing akan menjadi FixedNamafile.ext. <em>Say no to this file cannot be played.</em></p>
