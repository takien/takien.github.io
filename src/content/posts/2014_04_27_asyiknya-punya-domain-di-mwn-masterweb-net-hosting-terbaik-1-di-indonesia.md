<p>Waktu itu tahun <a href="/blog/2007/12/31/waktu-itu-tahun-2007/" target="_blank">2007 </a>adalah awal mula saya menggeluti dunia website, dimana walaupun masih newbie tapi berniat membeli hosting dan domain karena sebelumnya masih pakai gratisan. Sebagai pemula tentu belum punya banyak referensi mengenai hosting/domain provider yang baik. Dan pilihan saya tertuju pada sebuah perusahaan webhosting TERKENAL dan mengkalim yang terbaik di Indonesia, urutan nomor satu. Yaitu Masterweb.net dan biasa disingkat dengan MWN.</p>
<p>Tapi apa lacur, ternyata pilihan saya tersebut membawa dampak yang signifikan di sepanjang perjalanan hidup saya sampai 2014 ini. Dimana sebenarnya di tahun pertama juga saya sudah mengalami masalah dengan hosting nya. Yaitu database corupt, dan mereka tidak bertanggung jawab (sepertinya masih ada arsip email ticketnya, tapi saya malas mencarinya). Karena website sudah mulai ramai maka saya memutuskan untuk pindah hosting. Tidak ada masalah dalam pemindahan hosting, menyewa hosting baru, mencopy file-file dari hosting lama ke tempat yang baru, mengarahkan NS domain ke hosting baru. Selesai.</p>
<p>Tapi masih ada yang mengganjal, karena domain saya daftarkan di MWN, dan artinya masih dimiliki oleh MWN, bahkan informasi WHOIS nya pun masih atas nama MWN semua. Dan saya berniat memindahkan/mentransfer domain saya tersebut ke registrar baru pilihan saya. Ternyata tidak semudah yang dibayangkan, karena untuk memindahkan domain dari MWN itu tidak lebih mudah dari mengurus surat-surat kependudukan di kelurahan. Saya diminta menandatangani sebuah dokumen, menyertakan fotokopi KTP dan mengirim dokumen tersebut via pos ke kantor MWN setelah ditempeli materai.</p>
<p>Karena tidak mau ribet akhirnya saya menyerah dan memutuskan untuk tidak memindahkan domain tersebut ke registrar lain dan terus memperpanjang domaint tersebut di MWN.<br/>
Selama kurang lebih 7 tahun memiliki domain di MWN bukanlah hal yang mengasyikkan, selalu ada saja masalah yang timbul. Seperti ketika waktu perpanjangan tiba, saya sudah membayar dan konfirmasi tapi mereka tidak memperpanjang domain tersebut sampai expired. Kejadian seperti itu terjadi di 2012 dan 2013. Sampai akhirnya dengan terpaksa saya memaki-maki CS nya untuk mengurusi hal tersebut. Walau sebenarnya kasihan juga, mereka cuma bekerja dan mendapatkan gaji.</p>
<p>Sampai akhirnya di awal April 2014 lalu MWN mengirimkan invoice untuk perpanjangan domain lagi. Sedikit terkejut karena biayanya adalah Rp150ribu. Hmmm.. sepertinya ini momen yang tepat untuk melepaskan domain saya dari MWN. Dan&#8230; selama kurun waktu tersebut ternyata MWN masih saja tidak berubah, semuanya serba ribet dan merugikan pelanggan.</p>
<p>Saya masuk ke domain manager mencoba mencari EPP Code (kode untuk transfer domain), tapi ternyata dilock. Lagi-lagi harus menghubungi customer service untuk memproses masalah sesimpel ini.</p>
<p>Sebagaimana kita ketahui bahwa proses transfer domain antar registrar tidak seharusnya ribet.</p>
<p>Cara transfer domain pada umumnya:</p>
<ol>
<li>Login ke panel domain</li>
<li>Cari menu EPP Code</li>
<li>Di registrar baru, order transfer. Kemudian di minta EPP code dari registrar lama</li>
<li>Konfirmasi email</li>
<li>Done</li>
</ol>
<p>Namun, apakah itu berlaku di MWN? Tidak, beginilah cara yang harus saya tempuh untuk memulai transfer domain dari MWN. Proses berikut memakan waktu hampir sebulan.</p>
<ol>
<li>Saya login ke panel domain</li>
<li>EPP code tidak dapat diakses (authentication failed blabla, sengaja diblock mereka)</li>
<li>Kirim support Chat, tidak dibalas</li>
<li>Kirim Ticket ke support &amp; billing (sengaja ke 2 divisi)</li>
<li>Support bilang masuk ke menu domain trus klik request EPP. (Ketauan support gk ngerti sistem mereka sendiri, bahwa fasilitas itu di block).</li>
<li>Billing balas: &#8220;Kalau mau transfer out, silakan isi form&#8221; diarahkan ke form, saya isi, nama domain dan alasan transfer out. Saya bilang aja &#8220;kemahalan&#8221;.</li>
<li>Billing balas lagi: Oke untuk proses transfer, Kita yang akaan memprosesnya. Bapak harus membayar dulu tagihan nomer sekian, yang sudah kami revisi. Sempat shock kirain disuruh bayar 150rb, tapi ternyata invoice udah mereka revisi, jadi sekitar 80-an ribu.</li>
<li>Saya konfirmasi pembayaran.<br/>
Proses dari no 1 &#8211; 8 di atas memakan waktu up to 2 hari lebih, tau sendiri kan kalau balas-balasan ticket support MWN, jgn pernah harap cepat dibalas, udah gitu jam 11 baru buka, jam 3 udah tutup, hari libur tutup, weekend tutup.</li>
<li>Billing ticket balas, udah menerima pembayaran, transfer sedang diproses.</li>
<li>Saya bingung, &#8220;Ini proses apa ya yang katanya sedang berlangsung?, bukannya saya belum order transfer di regsitrar baru dan tidak pernah memberitahu mereka tentang registrar baru, kok tiba2 mereka bilang transfer sedang diproses.</li>
<li>Tidak mau panik, saya sabar menunggu beberapa hari hari, dan mereka bilang transfer sudah selesai. Dan dapat email bahwa saya diminta klik link tertentu untuk konfirmasi perubahan data WHOIS (sepertinya). Saya klik.</li>
<li>Sepertinya domain saya sekarang nowhere, hahaha. Setidaknya tidak di MWN lagi, walau di panel domain masih ada. EPP Code tidak ada, bagaimana mau order transfer di registrar baru? What a week of wasting my life.</li>
</ol>
